METHODPUT
ROUTE/organizations/{organizationSlug}/work-units/{workUnitId}/pm-classification
DESCRIPTIONReplace a work unit PM classification using optimistic concurrency. A no-op returns the current DTO with 200. Errors use RFC 9457 result:work-unit-pm-classification:* problem types (400 empty/invalid-task-id, 403 forbidden, 404 work-unit/project-not-found, 409 stale-version/project-unavailable).
AUTHENTICATION
  • Bearer
BEHAVIOURPUT /organizations/{organizationSlug}/work-units/{workUnitId}/pm-classification should
be inaccessible for a non-authenticated user -> [401]
return 200 and the exact DTO when the service reports Ok, including a no-op -> [200]
return 400 for empty and invalid-task-id errors with their exact extensions -> [400]
return 403 for Forbidden with an empty extension -> [403]
return 404 for work-unit-not-found and project-not-found with their exact extensions -> [404]
return 409 for stale-version and project-unavailable with their exact extensions -> [409]
