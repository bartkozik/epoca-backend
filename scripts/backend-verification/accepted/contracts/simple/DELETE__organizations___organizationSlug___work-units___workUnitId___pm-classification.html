METHODDELETE
ROUTE/organizations/{organizationSlug}/work-units/{workUnitId}/pm-classification
DESCRIPTIONClear a work unit PM classification using required expectedVersion optimistic concurrency. A no-op returns the inactive current DTO with 200. Errors use RFC 9457 result:work-unit-pm-classification:* problem types (403 forbidden, 404 work-unit-not-found, 409 stale-version).
AUTHENTICATION
  • Bearer
BEHAVIOURDELETE /organizations/{organizationSlug}/work-units/{workUnitId}/pm-classification should
be inaccessible for a non-authenticated user -> [401]
return 400 when expectedVersion is missing before invoking the service -> [400]
return 200 and the exact inactive DTO when the service reports Ok, including a no-op -> [200]
return 403 for Forbidden with an empty extension -> [403]
return 404 for WorkUnitNotFound with an empty extension -> [404]
return 409 for StaleVersion with the currentVersion extension -> [409]
