METHODPOST
ROUTE/organizations/{organizationSlug}/work-units
DESCRIPTIONCreate a Worklog or Note. duration is required and positive for Worklog; for Note it may be omitted/null and defaults to PT0S. entryType defaults to Worklog and userId defaults to the authenticated user.
AUTHENTICATION
  • Bearer
BEHAVIOURPOST /organizations/{organizationSlug}/work-units should
be inaccessible for no-logged user -> [401]
decode legacy missing and explicit null entryType/userId as defaultable fields
decode future Note with missing or null duration and return PT0S plus entryType
reject unknown and mis-cased entryType with the existing static validation problem
return NotFound if service returns OrganizationNotFound -> [404]
return BadRequest if service returns NonPositiveDuration -> [400]
return BadRequest if service returns NonNeutralNoteDuration -> [400]
return BadRequest if service returns FutureWorklogDate -> [400]
return Forbidden if service returns NoAccessToTargetUser -> [403]
return Forbidden if service returns TargetUserNotAssignedToProject -> [403]
return NotFound if service returns TargetUserNotFound -> [404]
return NotFound if service returns NoAccessToOrganization -> [404]
return NotFound if service returns ProjectNotFound -> [404]
return Forbidden if service returns NoAccessToProject -> [403]
return identical problem status and type with and without Idempotency-Key
without Idempotency-Key return the legacy Created response and call create once -> [201]
document Idempotency-Key as optional
with a canonical UUID call the idempotency facade and return its first exact response
replay a stored custom status 299 and exact body with one replay header -> [299]
fail with InternalServerError for an invalid persisted status 600 without a silent fallback -> [500]
reject an invalid Idempotency-Key before invoking either service
reject a noncanonical UUID accepted leniently by UUID.fromString -> [202]
return Conflict (409) for an idempotency key conflict with the exact problem response -> [409]
return Conflict (409) for an unsupported idempotency version with the exact problem response -> [409]
return 410 Gone for an expired idempotency result with the exact problem response -> [410]
