METHODGET
ROUTE/organizations/{organizationSlug}/work-units/{workUnitId}/pm-classification/history
DESCRIPTIONReturn the exact PM classification history snapshot page. upToVersion is required; pageSize and pageNumber must be supplied together or omitted for service defaults 25/1. Errors use RFC 9457 result:work-unit-pm-classification:* problem types (400 invalid-pagination, 403 forbidden, 404 work-unit-not-found).

return 200 with the exact page and delegate omitted pagination to service defaults -> [200]
return 200 while forwarding pageSize and pageNumber together without changing their meaning -> [200]
return 400 for both invalid pagination fields with the exact field extension -> [400]
return 403 for Forbidden with the exact problem type and empty extension -> [403]
return 404 for WorkUnitNotFound with the exact problem type and empty extension -> [404]
